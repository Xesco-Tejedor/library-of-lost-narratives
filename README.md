# Library of Lost Narratives

Un laboratorio de lectura entre hojas, pétalos y piedras. Reconstruye una narrativa académica a partir de fragmentos, sin confundir evidencia con hipótesis.

## Primera versión

- Mesa visual: explorar, seleccionar y ordenar fragmentos en Introducción, Método, Resultados y Discusión.
- Corpus ficticio de demostración, identificado como tal. No contiene artículos históricos reales ni citas inventadas presentadas como auténticas.
- Añadir fragmentos propios con procedencia, responsable y estado de evidencia.
- Notas por fragmento y comparación de pares con conexiones locales o ayuda de IA optativa.
- Guardado en este navegador, exportación de proyectos JSON y fusión revisable de aportaciones. No hay cuentas, servidor de colaboración ni edición simultánea.
- Exportación del borrador a Markdown con fuentes, vacíos e hipótesis visibles.

## IA y privacidad

Las sugerencias no recuperan texto perdido ni prueban una relación histórica. La IA solo recibe los dos fragmentos seleccionados tras marcar el consentimiento. La ruta gratuita del intermediario existente mantiene las claves fuera del cliente. Puede agotar cuota o fallar; hay un límite de espera y la app sigue funcionando sin IA. No se han contratado servicios de pago.

Los proyectos y notas se guardan en almacenamiento local del navegador. Los archivos exportados incluyen el texto, las fuentes y los nombres de quienes aportan notas: revísalos antes de compartirlos. Importar un proyecto añade fragmentos nuevos y notas, sin sobrescribir el orden del proyecto actual. El orden recibido se muestra como propuesta para revisión. No subas material confidencial al proveedor de IA.

## Uso

Abre index.html en un navegador moderno o la demo en GitHub Pages. Pulsa un fragmento para leerlo y colócalo en una sección. Usa los controles de subir, bajar o devolver a la mesa para organizarlo sin arrastrar. Puedes arrastrarlo en escritorio. Selecciona dos para comparar sus conexiones. Descarga el proyecto para trabajar con otra persona y luego fusiona su archivo.

Este prototipo no sustituye el cotejo con originales, la crítica textual, la revisión humana ni una edición académica.
